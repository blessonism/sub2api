# Token 用量自动分组倍率策略

## Goal

实现管理员可配置的 Token 用量自动分组倍率策略：按用户近 7/30 天 Token 用量命中有序档位，自动设置目标分组下的用户专属倍率，或同时授权目标分组。支持自动降档/清除、可配置执行频率、手动预览、立即执行、执行历史，并默认手动设置优先。

## Requirements

- 管理员可以创建、编辑、启停 Token 用量自动策略。
- 每条策略固定一个目标分组，同一目标分组同一时间只允许一条启用策略。
- 每条策略包含多个有序档位；档位只配置最小 Token 阈值和目标倍率。
- 执行时按用户窗口期 Token 用量选择命中的最高档位；低于最低档时清除本策略产生的配置。
- 窗口期支持 7 天和 30 天，按滚动窗口计算。
- Token 阈值口径为输入 Token + 输出 Token + 缓存创建 Token + 缓存读取 Token。
- 只统计成功落账请求，失败或未落账请求不进入阈值判断。
- 策略筛选范围支持分组、模型、请求类型、计费类型；默认不筛选，即全站总用量。
- 动作模式支持：
  - 仅设置专属倍率：只写入目标分组下的用户专属倍率。
  - 授权分组并设置专属倍率：新增/保留目标分组授权，同时写入专属倍率。
- 授权分组模式不删除用户已有旧分组；清除时只移除本策略新增的目标分组授权。
- 冲突策略支持：
  - 手动设置优先：默认值。管理员手动改过倍率或分组授权后，自动规则不再覆盖对应用户配置。
  - 自动规则优先：规则执行可按命中档位覆盖自动管理范围内的配置。
- 自动降档或清除只能处理由本策略产生的配置，不能误删管理员手动设置。
- 自动写入不能破坏现有 RPM override 或其它用户专属配置。
- 执行频率支持 every_6h、daily、weekly。
- 支持定时自动执行、手动预览、立即执行和执行历史。
- 预览只返回将新增、更新、降档、清除、跳过的用户列表，不写入数据库。
- 同一策略不能并发执行。

## Acceptance Criteria

- [ ] 管理员能配置至少一条近 7/30 天 Token 阈值到分组专属倍率的策略。
- [ ] 同一目标分组同一时间只能启用一条自动策略。
- [ ] 管理员能选择动作模式、执行频率、冲突策略和统计筛选范围。
- [ ] 系统使用四项 Token 之和判断档位，并排除失败/未落账请求。
- [ ] 筛选范围只影响用量聚合和档位命中，不隐式改变目标分组。
- [ ] 预览不会写入任何用户配置或执行归属记录。
- [ ] 立即执行与定时执行产生一致变更和执行记录。
- [ ] 命中用户获得目标分组下的专属倍率。
- [ ] 授权分组模式会授予目标分组访问权，但不会删除旧分组。
- [ ] 用量下降后自动切换到低档倍率。
- [ ] 不再满足任何档位后，系统清除本策略产生的专属倍率/分组授权。
- [ ] 手动设置优先时，自动规则不会覆盖管理员手动接管的配置。
- [ ] 自动规则优先时，规则执行可按命中档位覆盖自动管理范围内的配置。
- [ ] 执行历史可追溯成功、失败、变更数量和错误原因。

## Technical Approach

- 新增自动策略、档位、归属记录和执行历史四类数据模型。
- 复用现有用户专属分组倍率能力写入 `(user_id, group_id) -> rate_multiplier`。
- 授权分组模式复用现有用户 allowed groups 能力。
- 新增策略服务负责校验、预览、执行、降档、清除和执行记录。
- 新增调度执行器，按 `next_run_at` 扫描到期策略，并使用策略级锁避免并发。
- 新增管理员 API 前缀 `/api/v1/admin/token-usage-policies`。
- 前端新增管理员页面 `/admin/token-usage-policies`，提供策略列表、表单、预览、立即执行和历史展示。

## Out of Scope

- MVP 不做迁移并移除旧分组。
- MVP 不做单策略内不同档位分配不同目标分组。
- MVP 不做同一目标分组多策略优先级或最优惠倍率合并。
- MVP 不开放自由 cron 表达式，只提供受控频率枚举。
