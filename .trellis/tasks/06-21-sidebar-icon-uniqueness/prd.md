# 侧栏图标优化

## 目标

优化前端侧栏导航的图标语义，尽量避免同一视图内不同按钮复用同一个图标，提升折叠侧栏下的可辨识度。

## 需求

- 保持现有侧栏导航顺序、路由、权限、功能开关和外链行为不变。
- 为明显语义不同的菜单项使用不同图标，重点覆盖用户侧栏、管理员侧栏和管理员分组子菜单。
- 沿用 `frontend/src/components/layout/AppSidebar.vue` 现有手写 SVG 图标组件风格，不新增前端依赖。

## 验收标准

- [x] 用户侧栏中用量、排行榜、外部支付、购买订阅等菜单项不再使用完全相同的图标。
- [x] 管理员侧栏中 Token 排行榜、余额汇总、运营监控、订阅、分销、订单等明显不同菜单项尽量使用不同图标。
- [x] 侧栏折叠、展开、分组展开、外链跳转和现有功能开关行为不受影响。
- [x] 前端类型检查通过。

## 范围外

- 不重构侧栏组件结构。
- 不调整菜单文案、路由、权限逻辑或 i18n key。
- 不替换为第三方图标库。

- 主要影响文件：`frontend/src/components/layout/AppSidebar.vue`。
