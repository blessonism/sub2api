# 用户排行榜展示阶梯优惠倍率

## 背景

用户侧 Token 排行榜目前只展示排名、脱敏用户、Token 和请求数。需要在 Token 列左侧增加优惠倍率展示，让用户感知阶梯优惠，刺激继续使用。

## 目标

- 用户侧排行榜新增“优惠倍率”列，位置在 Token 列左侧。
- 自动策略命中的用户展示 Token 用量自动分组倍率策略当前生效倍率。
- 未命中自动策略的用户展示管理员配置的全局通用分组倍率。
- 管理员 Token 排行榜提供配置入口，用于选择该全局通用分组。

## 约束

- 通用分组仅允许选择标准计费、非独占分组。
- 管理员配置的是展示兜底来源，不自动把用户加入该分组，也不改变真实扣费逻辑。
- 普通用户接口仍然只返回脱敏身份，不暴露用户 ID、邮箱或管理员字段。
- 排行榜排名、Token 统计周期和自动策略执行逻辑保持不变。

## 验收

- 自动策略命中用户显示自动策略倍率。
- 未命中用户显示配置的通用分组倍率。
- 未配置通用分组时有稳定兜底展示，不影响排行榜加载。
- 管理员可以在管理员 Token 排行榜页面选择和保存全局通用分组。
- 后端与前端测试覆盖新增响应字段、配置读写和 UI 展示。
