# 上游倍率监控今日用量概览卡

## Goal

在管理员“上游倍率监控”页面顶部概览区新增“今日用量”卡片，展示各连接器今日所有上游分组的总用量。

## What I Already Know

- 顶部概览当前已收敛为连接器状态、候选状态、最近同步三张卡，并且 Priority tab 使用纯数字徽章。
- 用户确认新增“今日用量”独立卡片，不塞进连接器状态卡。
- 主数字使用 tokens，并按 M / million 展示，例如 `1.25M`。
- 金额/成本只作为辅助信息展示。
- 统计范围必须是各连接器下所有上游分组，不是候选映射子集。
- 当前 `snapshots` 状态只表示选中连接器的快照，不能直接作为全局汇总来源。

## Requirements

- 新增顶部概览卡“今日用量”。
- 主值汇总所有连接器快照的 `today_total_tokens`，按百万 token 显示。
- 辅助信息汇总所有连接器快照的 `today_actual_cost`。
- 页面加载时为已加载连接器获取全量分组快照，用于概览汇总。
- 连接器同步或轻量刷新返回快照后，更新该连接器在概览快照集合中的数据。
- 不改变策略预览 tab、Priority tab badge、候选表或连接器表业务逻辑。

## Acceptance Criteria

- [ ] 顶部概览展示四张卡：连接器状态、候选状态、今日用量、最近同步。
- [ ] 今日用量 tokens 以 `M` 为单位显示。
- [ ] 今日用量辅助文案显示成本/金额。
- [ ] 今日用量统计来源为连接器快照，不依赖候选映射数量。
- [ ] 中英文 i18n key 同步。
- [ ] 定向视图测试和前端类型检查通过。

## Out of Scope

- 不新增后端聚合接口。
- 不调整策略预览 tab 内部卡片。
- 不修改实际用量同步逻辑或数据库结构。

## Technical Notes

- 快照 API 为 `listSnapshots(connectorId)`，返回 `today_total_tokens` 与 `today_actual_cost`。
- 为避免与选中连接器快照混淆，本次新增独立 `overviewSnapshots` 供顶部概览汇总使用。
