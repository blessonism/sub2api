# 修复用户排行榜倍率回退

## 背景

用户侧 Token 排行榜的“阶梯倍率”列依赖后端返回的 `discount_rate_multiplier`。当前管理员选择“未命中展示分组”后，如果该分组只配置了真实倍率、没有单独配置可见倍率，普通用户侧仍显示 `-`。自动阶梯命中时也存在同类问题：命中的分组没有可见倍率时，查询没有回退到真实倍率。

## 目标

- 自动阶梯命中时，优先显示用户专属可见倍率，再显示目标分组可见倍率，最后回退到用户专属真实倍率或目标分组真实倍率。
- 未命中自动阶梯时，管理员配置的未命中展示分组应优先使用分组可见倍率，缺省时回退到分组真实倍率。
- 保持用户侧响应契约不变，不暴露原始邮箱或内部用户 ID。

## 验收

- 命中自动阶梯但未配置可见倍率时，用户侧排行榜显示真实阶梯倍率。
- 未命中自动阶梯且未命中展示分组未配置可见倍率时，用户侧排行榜显示该分组真实倍率。
- 现有用户排行榜仓储测试通过，并覆盖新的 SQL 回退语义。
