# user campaign reward time display polish

## Goal

优化用户邀请活动页 hero 区的时间信息层级，避免左侧活动起止时间与右侧倒计时卡片重复表达同一个结束时间，让第一屏更聚焦“还剩多久”和“奖金激励”。

## What I already know

- 用户反馈当前第一个卡片显示“距活动结束 / 目标时间”，左侧又显示完整起止时间，信息重复。
- 当前页面位于 `frontend/src/views/user/CampaignRewardsView.vue`。
- 当前 hero 左侧展示活动名称、描述、生命周期说明和 `start_at → end_at`；右侧竖排展示倒计时卡片与预计总奖金池卡片。
- 右侧栏宽度有限，不适合把两个卡片强行横向并列。

## Requirements

- 移除 hero 左侧的完整起止时间展示。
- 保留右侧倒计时卡片和预计总奖金池卡片的竖排结构。
- 活动进行中时，把倒计时卡片的辅助时间文案从“目标时间”改为更明确的“结束时间”。
- 其他生命周期阶段使用对应阶段语义的辅助时间文案，避免泛化的“目标时间”。
- 在 hero 左侧补充无卡片化的活动周期 meta 行和轻量辅助线，填补视觉空白但不恢复完整时间戳。
- 优化活动规则卡片摘要，让用户能快速扫读有效邀请门槛、奖金池分配、审核结算说明。
- 修正规则区双列布局，避免完整规则收起时右侧卡片被左侧邀请入口卡拉高后留下大量空白。
- 保留完整规则折叠区，展开后仍展示后端活动配置的 `rules_text`。

## Acceptance Criteria

- [ ] 用户邀请活动页 hero 左侧不再展示 `start_at → end_at` 时间范围。
- [ ] 活动进行中状态下，倒计时卡片展示“结束时间：{time}”。
- [ ] 预计总奖金池卡片仍与倒计时卡片在右侧竖排展示。
- [ ] hero 左侧展示短日期活动周期、当前进度文案和真实进度线，且不使用 `→` 展示完整起止时间。
- [ ] 相关用户邀请活动页测试覆盖重复时间移除和结束时间文案。
- [ ] 活动规则卡片展示生产化摘要要点，且用户可继续展开查看后端配置完整规则。
- [ ] 规则卡收起状态不被同一 grid 行强制拉伸出明显空白。

## Out of Scope

- 不调整排行榜、邀请记录列表。
- 不重构活动生命周期计算逻辑。
- 不改变后端活动数据结构。
