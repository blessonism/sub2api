# 修复抽奖倒计时结束状态展示

## 背景

最近的抽奖活动 UI 打磨提交中，用户侧倒计时在开奖时间已经过去时会回退显示“待开奖”。这会掩盖真实的开奖时间，尤其影响单次抽奖已经到点但结果尚未处理、或用户查看活动历史状态的场景。

## 目标

- 倒计时仍未结束时，保留当前倒计时块与下方开奖时间说明。
- 倒计时已经结束但存在 `next_draw_at` / `draw_at` 时，展示实际开奖时间，不再展示“待开奖”。
- 没有任何开奖时间时，仍允许展示“待开奖”兜底。
- 增加组件测试覆盖已过开奖时间的展示，防止回归。

## 非目标

- 不改动后端抽奖窗口计算逻辑。
- 不调整抽奖活动的数据结构或 API 契约。
