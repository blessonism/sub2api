# OVH mihomo 与 Sub2API 代理链路只读执行计划

## 执行步骤

- [x] 校验 `ssh ovh` 的实际目标、系统时间和主机身份。
- [x] 识别 mihomo 的运行方式，采集状态、监听、启动时间和近期有限日志。
- [x] 对照宿主机直连与经 mihomo 的 HTTP/HTTPS、DNS 和出口地址探测。
- [x] 识别 Sub2API 的运行方式、网络和脱敏后的代理地址来源。
- [x] 从 Sub2API 运行网络验证 mihomo 端口，并采样近期代理相关错误日志。
- [x] 交叉验证各层证据，输出根因、置信度、影响范围和分级修复建议。

## 验证标准

- 每个结论至少对应一个可复核的运行状态、网络结果、配置字段或日志证据。
- mihomo 自身、mihomo 出站、Sub2API 到 mihomo、Sub2API 实际代理选择四层均有明确结果。
- 未发现生产写操作、服务重启、配置修改、数据库读取或带凭据请求。

## 风险与停止条件

- SSH 目标与预期 OVH 主机不一致时停止。
- 命令可能输出订阅、认证信息、完整环境变量或用户数据时停止并改用字段过滤。
- 需要重启、重载、切换节点、修改配置、执行生产业务请求或数据库查询时停止并请求确认。
- 探测造成明显资源波动或服务异常时立即停止。
