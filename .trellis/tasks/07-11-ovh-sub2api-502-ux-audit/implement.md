# OVH Sub2API 502 只读排障执行计划

## 执行步骤

- [ ] 确认 `ovh` SSH 目标可达，并记录不含秘密的连接与系统概要。
- [ ] 采集宿主机资源、Docker 容器、健康、重启和资源限制快照。
- [ ] 识别公网到应用的代理链路及当前生效的超时、流式、连接和并发配置。
- [ ] 按 request id 关联反代与应用日志，并在必要时采样近期同类 502。
- [ ] 汇总根因、放大因素、可观测性缺口和按严重度排序的整改建议。

## 验证

- 样例 request id 在各层日志中的命中结果可复核。
- 关键判断同时具有配置或运行状态证据，以及对应日志证据；无法双重验证时明确降低置信度。
- 检查命令历史中不存在写配置、重启、部署、数据库变更或带凭据的 API 请求。

## 风险与停止条件

- SSH 目标与预期生产机不一致时停止。
- 命令可能输出秘密或大量用户数据时停止并改用字段过滤。
- 发现需要重启、重载、修改配置、执行生产 API 或数据库操作时停止，先向用户申请明确确认。
