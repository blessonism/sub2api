# 独立账号编组与快捷筛选

## Goal

新增与业务分组隔离的账号编组、批量归组及账号页快捷筛选

## Requirements

- 新增与现有计费/调度业务分组完全隔离的“账号编组”，一个账号可加入多个账号编组。
- 管理员可在账号页内创建、改名、排序、删除账号编组；删除编组只解除关联，不删除账号。
- 管理员可勾选多个账号，对多个账号编组执行增量加入或移出，重复操作保持幂等。
- 账号列表支持按单个账号编组筛选，并与平台、状态、业务分组和搜索条件按 AND 组合。
- “添加账号”右侧展示横向快捷标签；筛选某编组时创建账号，默认预选该编组。
- 创建和编辑账号时可维护账号编组归属。
- 账号编组不得影响调度、计费、权限、模型路由或现有业务分组。

## Acceptance Criteria

- [x] 账号编组 CRUD、排序和多对多关系可通过管理员 API 完成，活动名称唯一。
- [x] 批量加入/移出保留未涉及的编组关系，删除编组保留账号及其其他关系。
- [x] 账号列表分页筛选正确，并提供按账号查询编组摘要的管理员接口。
- [x] 快捷标签支持“全部”和单选切换，超宽时可横向滚动且不挤压操作按钮。
- [x] 创建、编辑、批量归组和页内管理交互完整，并提供中英文文案。
- [x] 后端和前端针对核心路径、错误路径和幂等行为的测试通过。

## Notes

- 第一版不提供颜色、层级、权限、共享范围、账号数量统计或自动规则。
- API、数据库和代码符号使用 `account_collection`，界面统一使用“账号编组”。
