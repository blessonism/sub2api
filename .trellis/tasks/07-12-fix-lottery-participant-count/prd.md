# 修复抽奖实际参与人数统计

## Goal

用户侧参与人数应统计当前开奖轮次已实际报名的去重用户，而不是仅达到用量门槛的可参与用户。

## Requirements

- 用户侧 `participant_count` 必须表示当前开奖轮次已实际报名的去重用户数。
- 统计范围必须限定为当前活动和当前 `entry_date`，且只包含 `lottery_entries.status = 'enrolled'`。
- 仅达到用量门槛但仍处于 `eligible` 状态的用户不得计入参与人数。
- 保持现有 API 字段名和前端展示契约不变。

## Acceptance Criteria

- [ ] 自动参与用户创建报名记录后会计入当前轮次参与人数。
- [ ] 手动参与模式下，仅达标但未报名的用户不会计入参与人数。
- [ ] 其他活动或其他开奖日期的报名记录不会计入当前轮次。
- [ ] 后端相关单元测试通过。

## Notes

- 本次不修改前端字段和文案，只修正后端统计来源。
