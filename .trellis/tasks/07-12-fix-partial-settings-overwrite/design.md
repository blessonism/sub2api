# 设计：局部设置写入隔离

## 边界

- `PUT /api/v1/admin/settings` 保持基础设置页的全量保存语义，并增加请求完整性门禁。
- 新增 `PUT /api/v1/admin/settings/token-leaderboard`，请求体只包含排行榜公共分组和提示文案。
- 排行榜 handler 直接构造当前完整设置的受控副本，或调用只写指定键的 service 方法；优先提供窄 service 方法，使数据库写集合天然受限。
- 前端删除通用更新函数的 `Partial` 参数，排行榜页面改用专用 API。

## 防护

通用接口在 JSON 绑定前读取字段存在性，校验一组基础设置页稳定且非敏感的必需字段。请求不完整时返回 `INVALID_SETTINGS_REPLACE_REQUEST`，且不调用 repository。该门禁用于阻止当前及未来页面误用全量接口。

排行榜专用接口复用既有分组合法性和提示文案长度规则，只写两个设置键。响应返回专用 DTO，避免调用方误以为获得完整系统设置。

## 测试

- handler 测试验证局部请求被全量接口拒绝。
- 专用接口测试验证绑定、响应和路由。
- service 测试预置无关设置，更新排行榜后断言无关值未变化。
- 前端 API 测试验证专用路径，类型检查验证全量接口不能接收 Partial。

## 回滚

代码回滚不涉及数据库结构。生产发布失败时恢复上一应用镜像；已存在的配置数据不会被迁移或转换。
