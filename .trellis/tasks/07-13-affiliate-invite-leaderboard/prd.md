# 管理后台全局邀请排行榜

## Goal

在“邀请返利”管理菜单下提供全站邀请人排行榜，帮助管理员同时观察累计邀请人数、受邀用户全部正向余额增加，以及支付和余额兑换码带来的累计额度。

## Requirements

- 新增独立管理页面 `/admin/affiliates/leaderboard`，不改变现有邀请、返利和提取记录页面。
- 榜单仅包含未删除且累计邀请人数大于 0 的邀请人。
- 固定按累计邀请人数降序、支付及余额兑换码额度降序、邀请人 ID 升序排名。
- 展示全局名次、邀请人身份、邀请码、累计邀请人数、所有额度增加、支付及余额兑换码额度。
- 所有额度增加汇总受邀用户的 `users.total_recharged`。
- 支付及余额兑换码额度汇总受邀用户已使用且金额为正的余额兑换码；支付订单生成的兑换码只计一次。
- 支持分页及按邀请人邮箱、用户名、用户 ID、邀请码搜索，搜索后保留全局名次。
- 两种额度均为历史累计入账总额，不因退款、消费或负向调整而减少。
- 不新增数据库表或迁移，不引入新的余额流水体系。

## Acceptance Criteria

- [x] 管理员可通过邀请返利侧栏进入独立排行榜页面。
- [x] 榜单聚合字段、排序、并列顺序和分页稳定且正确。
- [x] 支付生成的余额兑换码不会与支付订单重复累计。
- [x] 优惠码、管理员加款等奖励只进入“所有额度增加”。
- [x] 搜索结果保留邀请人在未筛选榜单中的全局名次。
- [x] 无邀请用户和已删除邀请人不进入榜单。
- [x] 中英文页面标题、说明、列名、空状态和错误提示完整。
- [x] 相关后端测试、前端定向测试和类型检查通过。

## Out of Scope

- 用户端公开榜单。
- 活动邀请排行榜改动。
- 时间区间筛选和非余额权益金额折算。
- 恢复已硬删除兑换码的历史金额。
