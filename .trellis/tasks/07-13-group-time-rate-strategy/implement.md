# 实施计划

1. 增加领域类型、Ent 字段和数据库迁移，生成 Ent 代码，并在仓储、DTO、管理员创建/更新流程及 API Key 缓存快照中贯通策略。
2. 用共享纯函数实现时间解析、区间校验、当前时间段匹配及三种真实/可见倍率优先模式；替换旧高峰倍率计费路径并覆盖所有继承倍率的计费类型。
3. 增加分组列表操作与 `GroupTimeRateStrategyModal`，删除新建/编辑分组中的旧高峰配置及用户侧旧高峰标签，用户响应改为当前可见倍率。
4. 增加后端单元/API/迁移测试和前端组件/页面测试，执行定向测试、Go 测试、前端类型检查与 lint 检查。
5. 复核普通用户字段白名单、缓存失效、旧字段清理和下游分支边界，记录检查结果。

## 回滚点

- 数据迁移在同一事务中新增、回填并删除旧字段；部署回滚需先恢复旧代码可读的新迁移前数据库备份。
- 不执行生产迁移或部署，本任务只提交可复现迁移脚本。

## 检查结果

- 后端定向服务、管理员 handler、API 契约和迁移回归测试通过。
- Go 全包编译检查通过。
- 前端弹窗 5 项交互测试通过，覆盖新增、默认倍率、重叠校验、撤销、启停、删除和脏数据关闭确认。
- 前端类型检查与 lint 检查通过。
- 普通用户响应仅返回请求时刻的当前可见倍率；管理员响应保留完整策略。
