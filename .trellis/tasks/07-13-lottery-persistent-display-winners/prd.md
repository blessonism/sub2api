# 抽奖活动常驻展示与中奖名单公开

## Goal

让管理员可以指定一场抽奖活动长期展示在用户活动中心，并在开奖后向管理员和普通用户持续展示可识别但不泄露敏感信息的中奖结果，避免活动结束后页面只剩空状态、用户无法确认开奖结果。

## Confirmed Facts

- 抽奖活动已有 `is_featured` 字段和管理员“设为活动中心展示”操作，但服务层只允许仍在有效期内的已发布活动被设为展示活动。
- 用户侧 `/lottery-campaigns/active`、个人活动数据、参与者和公开中奖名单都使用“已发布且当前时间位于活动时间范围内”的可见性判断，因此活动结束后无法继续查看。
- 后端已经持久化 `lottery_winners`，管理员 API 已提供按活动查询中奖记录，用户 API 也已提供脱敏后的成功中奖记录；当前主要缺口是可见性规则和管理员页面缺少中奖名单视图。
- 公开中奖记录只包含脱敏邮箱、奖项、奖金和中奖时间，不暴露用户 ID、余额快照或幂等键。

## Requirements

- 管理员可以将一场抽奖活动指定为用户活动中心的常驻抽奖活动，不因活动结束或当前没有新的已发布活动而自动消失。
- 常驻选择具有明确优先级：即使后来发布新的进行中活动，用户页面仍展示管理员当前指定的常驻活动，直到管理员手动切换。
- 用户打开活动中心时，可继续看到被管理员指定的常驻抽奖活动及其已结束状态。
- 常驻活动结束后不得继续报名或改变抽奖资格，只开放只读的活动信息与开奖结果。
- 管理员选择任意抽奖活动时，都能查看该活动已产生的中奖名单和发放状态。
- 普通用户能查看常驻活动的公开中奖名单，身份信息必须保持脱敏。
- 中奖名单来自已持久化的中奖记录，页面刷新、服务重启或活动结束后仍然存在。
- 不改变中奖算法、奖金发放和开奖幂等逻辑。

## Acceptance Criteria

- [x] 管理员可把已结束且已发布的抽奖活动设为常驻展示。
- [x] 没有当前进行中的新抽奖活动时，用户活动中心仍返回并展示常驻活动。
- [x] 用户查看已结束常驻活动时，无法报名，但能看到公开中奖人、奖项、奖金和中奖时间。
- [x] 管理员活动详情能查看完整中奖记录，包括用户标识、奖项、金额、状态和时间。
- [x] 非常驻且已结束/取消/草稿活动不会通过用户 API 暴露。
- [x] 后端与前端测试覆盖常驻可见性、只读状态和中奖名单展示。

## Out of Scope

- 不新增抽奖历史列表或多活动切换器。
- 不修改开奖随机算法、指定中奖逻辑或余额发放流程。
- 不公开用户真实邮箱或其他敏感字段。
