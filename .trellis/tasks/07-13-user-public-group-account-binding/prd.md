# 公开分组用户账号绑定

## Goal

允许管理员按“用户 + 标准公开分组”为用户限定一个或多个上游账号，并在严格限制与不可立即承接时回退分组账号之间选择策略。

## Requirements

- 未配置绑定时保持现有调度行为。
- 绑定只允许用于标准公开分组，账号必须存在且属于对应分组。
- 严格模式不得选择绑定列表之外的账号；绑定账号并发已满时沿用现有等待机制。
- 回退模式先尝试绑定账号；没有可立即承接请求的绑定账号时使用分组其他账号。
- 策略覆盖 Anthropic、OpenAI/Grok、Gemini/Antigravity 实时请求及 OpenAI WebSocket，不覆盖异步批量任务。
- 配置读取失败时拒绝调度，不能按未配置处理。
- 管理员在现有用户分组配置弹窗中完成配置，普通用户不可见。

## Acceptance Criteria

- [x] 管理员可为一个用户在不同公开分组配置不同账号列表与回退策略，并可清空配置。
- [x] 非公开分组、空账号列表、非分组账号或不存在账号会被后端拒绝。
- [x] 严格模式的粘性会话、模型路由、调度快照和重试均不会越过绑定列表。
- [x] 回退模式在绑定账号无法立即承接时可使用分组其他可用账号。
- [x] 未配置用户、专属分组和其他用户的行为不变。
- [x] 后端迁移、仓储、调度和前端组件具有针对性自动化测试。

## Out of Scope

- 普通用户自助配置或查看绑定。
- 批量图片等异步任务调度。
- 按 API Key 单独配置账号绑定。
