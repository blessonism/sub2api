# 管理员批量缩减用户余额 - 实施计划（待用户确认后执行）

## 1. 后端契约与数据库操作

- 校验有限小数输入（`x > 1`、最多 8 位小数），使用 numeric 计算并按 8 位小数落库。
- 增加只读预览接口：固定查询 `deleted_at IS NULL`，返回用户数、当前总余额、目标总余额、减少总额。
- 增加幂等执行接口：在单事务内原子缩减余额、写入逐用户 `admin_balance` 记录，并返回实际结果。
- 复用现有管理员幂等、余额历史和缓存失效能力；不调用 N 次单用户 HTTP 接口。

## 2. 管理员前端入口

- 在 `UsersView.vue` 工具区域增加“批量缩减余额”入口。
- 使用原生数值输入和明确的 `x > 1` 提示；提交前调用预览。
- 预览后用危险确认弹窗展示范围和金额，确认时发送幂等键；成功后刷新列表并提示实际影响。
- 补齐简体中文/英文文案和加载、失败、空用户、预览与执行结果状态。

## 3. 验证与回滚点

- 后端单测覆盖倍数校验、未软删除过滤、numeric 计算、事务失败整体回滚、审计记录和幂等重放。
- Repository/集成测试覆盖并发扣款不丢更新、零余额、极小余额舍入和全量用户范围。
- 前端测试覆盖非法倍数阻止、预览展示、二次确认、重复提交和成功刷新。
- 回滚代码时移除接口与入口；已落库余额不能依靠代码回滚自动恢复，需依据 operation id 和逐用户 delta 核对恢复。
- 第一版不实现自动撤销按钮或批量任务系统。
